# 阿里云长期部署指南

> 目标：把平台从 Sealos（免费但容器重启丢数据）迁移到阿里云，实现**数据持久化 + 长期稳定运行 + 自定义域名/HTTPS**。

---

## 一、选型与费用

| 方案 | 配置 | 价格 | 适合 |
|------|------|------|------|
| **轻量应用服务器**（推荐首选） | 2核2G / 200M峰值带宽 / 40G SSD | **新用户 ¥38/年**，日常 ¥68/年 | 本项目完全够用 |
| ECS 经济型 e 实例 | 2核2G / 3M固定带宽 | **¥99/年，续费同价** | 打算连续跑多年的稳定选择 |
| ECS u1 | 2核4G / 5M带宽 | ¥199/年 | 后期用户量上来再升级 |

**本项目资源评估**：单容器（React 静态前端 + FastAPI + SQLite），Sealos 上 0.5核/1G 就能跑，2核2G 有充足余量。带宽方面：页面首次加载约 900KB（gzip 后 240KB），200M 峰值带宽完全够一个班级规模使用。

> 学生党记得先做**阿里云高校学生认证（云工开物计划）**，经常有免费试用或大额代金券，叠加新用户价格更划算。

## 二、购买与初始化（约 15 分钟）

1. 购买轻量应用服务器，地域选**离学校近的**（如华北2-北京 / 华东1-杭州）
2. 应用镜像选 **Docker CE（Ubuntu 22.04 + Docker）**，省去手动装 Docker
3. 控制台 → 防火墙 → 放行端口：**80**（HTTP）、443（HTTPS，可选）、22（SSH）
4. 记下公网 IP，SSH 连接：
   ```bash
   ssh root@你的IP
   ```

## 三、部署（约 10 分钟）

```bash
# 1. 创建工作目录
mkdir -p /opt/ai-platform && cd /opt/ai-platform

# 2. 上传部署文件（本仓库 deploy/ 目录下三个文件）
#    docker-compose.prod.yml  deploy.sh  .env

# 3. 创建 .env（LLM_API_KEY 必填）
cat > .env << 'EOF'
LLM_API_KEY=你的DeepSeek密钥
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
EOF

# 4. GHCR 镜像若是私有仓库，先登录（GitHub → Settings → Developer settings → PAT，勾选 read:packages）
echo 你的PAT | docker login ghcr.io -u Scherlock07 --password-stdin

# 5. 启动
docker compose -f docker-compose.prod.yml up -d

# 6. 验证
curl http://localhost/docs
```

浏览器访问 `http://你的IP` 即可使用，数据存在 `/data` 卷中——**重启、升级、换容器都不丢**。

## 四、更新流程

本地改完代码 push 到 GitHub → Actions 自动构建推送 GHCR → 服务器执行：

```bash
bash /opt/ai-platform/deploy.sh
```

（想全自动可在 `docker-compose.prod.yml` 中启用 watchtower，push 后 5 分钟内自动更新。）

## 五、域名与 HTTPS（可选，推荐）

1. **域名**：阿里云买 `.top/.xyz` 首年 ¥5-10，或用已有的
2. **⚠️ 备案**：国内地域服务器 + 域名对外提供 web 服务，必须完成**ICP备案**（阿里云控制台全程线上办理，个人备案免费，约 1~2 周）。
   - 不想备案的替代：① 直接用 `IP` 访问；② 选**中国香港**地域免备案（延迟略高 30-50ms）
3. **HTTPS**：备案后到阿里云 SSL 证书控制台申请**免费个人版证书**（每年 20 张），按文档配到 nginx 反向代理即可；或最简方案——上 Caddy 自动 HTTPS。

## 六、数据备份

```bash
# 每日凌晨自动备份数据库（加到 crontab）
echo '0 3 * * * docker exec ai-language-platform sqlite3 /data/ai_language_platform.db ".backup /data/backup-$(date +\%F).db"' | crontab -
```

建议每月把备份文件下载一份到本地/网盘。
